# ARPlay Films

## Descrição

Este projeto consiste no desenvolvimento de um sistema web para a empresa ARPlay Films, especializada em cobertura audiovisual de eventos.
A aplicação foi desenvolvida como trabalho acadêmico com o objetivo de aplicar conceitos de desenvolvimento Full Stack, integrando front-end, back-end e banco de dados em uma solução completa para gerenciamento de orçamentos, clientes e eventos.

## Objetivos do Projeto

- Desenvolver uma aplicação web completa.
- Aplicar conceitos de HTML, CSS e JavaScript.
- Desenvolver uma API utilizando Python e Flask.
- Utilizar banco de dados SQLite para armazenamento das informações.
- Implementar funcionalidades de acessibilidade.
- Criar um sistema de gerenciamento de orçamentos e eventos.

## Funcionalidades

### Site Institucional

- Página inicial responsiva
- Apresentação da empresa
- Seção de serviços
- Portfólio de trabalhos realizados
- Perguntas frequentes (FAQ)
- Área de contato

### Sistema de Orçamentos

- Cadastro de solicitações de orçamento
- Validação de dados
- Geração automática de código para cada orçamento
- Armazenamento dos dados no banco de dados

### Painel Administrativo

- Login de administrador
- Listagem de orçamentos
- Pesquisa e filtros
- Alteração de status dos orçamentos
- Cadastro de novos registros
- Edição de informações
- Exclusão de registros
- Histórico de alterações

### Acessibilidade

- Aumento e redução de fonte
- Alto contraste
- Escala de cinza
- Destaque de links
